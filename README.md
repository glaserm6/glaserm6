## 🤖 ThinkPilot

### *An Adaptive Decision Framework for LLM-Assisted Programming Education*

ThinkPilot explores how an AI programming assistant can provide **different levels of assistance depending on what a student actually needs**.

Instead of immediately generating an answer, the system evaluates the student's interaction and selects an appropriate response strategy.

## 👁️ Eye Tracking & Concussion Research

Research exploring whether ordinary webcams can be used to collect meaningful eye-movement information for potential concussion detection.

The project combines:

- Computer vision
- Eye tracking
- Facial landmark detection
- Iris tracking
- Calibration
- Machine learning
- Neuroscience
